# Sprint 2 Controls

## Mario
- **Left Arrow** - Move left
- **Right Arrow** - Move right
- **Space Bar** - Jump
- **F** - Cycle through Mario's powerup states
- **L** or **Left Click** - Throw a fireball (as fire Mario) OR use F.L.U.D.D when wearing it

## General
- **Q** - Quit the game
- **R** - Reset the game to the base state of the current level
- **T** - Switch to the test level
- **M** - Switch to Mario 1-1
