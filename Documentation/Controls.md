# Sprint 2 Controls

## Mario
- **Left Arrow** - Move left
- **Right Arrow** - Move right
- **Space Bar** - Jump

## Enemies
- **P** - Select koopa
- **O** - Select goomba

## Items
- **T** - Cycle through item types

## Blocks
- **Mouse Click** - Interact with the tile object

## General
- **Q** - Quit the game
- **R** - Reset the game to the base state
