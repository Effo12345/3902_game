# Sprint 2 Controls

## Mario
- **Left Arrow** - Move left
- **Right Arrow** - Move right
- **Space Bar** - Jump
- **F** - Cycle through Mario's powerup states
- **L** or **Left Click** - Throw a fireball (as fire Mario) or hover (as sunshine mario)

## General
- **Q** - Quit the game
- **R** - Reset the game to the base state of the current level
- **T** - Switch to the sunshine level
- **M** - Switch to Mario 1-1
